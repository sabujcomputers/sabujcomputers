# Sabuj Computers — Smart Work Desk (Free)

A free, offline-first shop work manager for Sabuj Computers.

## Features
- Daily tasks with dates, priority and completion
- Prompt Library with categories and one-click copy
- Quick notes and pinned urgent notes
- Customer directory with optional phone/address
- Customer due/credit ledger: amount, received date, due date, partial payments and payment history
- Work templates/checklists
- Basic monthly income/expense tracking
- JSON backup/restore
- Mobile responsive
- No paid API or subscription required

## Data
This free build stores data in the browser's localStorage. Use Backup JSON regularly. A Supabase cloud-sync layer can be added later using the Supabase free tier when a project is available, but the app does not depend on it.

## Run
Open `index.html` in a browser, or host the folder with any free static hosting/GitHub Pages setup.
